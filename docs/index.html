Kudy jsem měl běžet?

Which way should I have run?

Program pro orientační běžce. Vezme tvůj běh z hodinek Garmin a mapu závodu z Liveloxu a u každého postupu ukáže, kudy jsi běžel, kudy by to pro tebe bylo nejrychlejší a kde jsi ztratil čas.

A tool for orienteers. It takes your run from a Garmin watch and the race map from Livelox and, for every leg, shows the route you ran, the fastest route for you and where you lost time.

Co to umí

What it does

Tvůj osobní model rychlosti

Your personal speed model

Z tvých závodů se naučí, jak rychle běžíš v jakém terénu a sklonu. Silný do kopce? Program to ví. Čím víc závodů nahraješ, tím je přesnější.

It learns from your races how fast you run in each terrain and slope. Strong on hills? It knows. The more races you add, the more accurate it gets.

Nejlepší postup pro tebe

The best route for you

Na každém postupu najde nejrychlejší cestu podle mapy a výškopisu a porovná ji s tou tvojí, i s vysvětlením.

For every leg it finds the fastest route from the map and the terrain model and compares it with yours, with an explanation.

Chyby u kontrol

Mistakes at controls

Pozná, kde jsi u kontroly kroužil nebo stál, a podle oficiálních mezičasů ukáže, kolik tě to stálo.

It spots where you circled or stopped near a control and uses the official splits to show how much time that cost you.

Bez umělé inteligence a bez placených služeb: jen geometrie, mapa a tvoje data.

Jak výpočet funguje pod kapotou
  • Z čisté mapy (bez tratě) program přečte barvy terénu: jak průběžný je les, kde vedou cesty a co je překážka (skála, voda, oplocenka).
  • Přidá podrobný výškopis (sklon svahu z modelu ČÚZK DMR 5G).
  • Podle tvého osobního rychlostního modelu z toho sestaví síť, kde každé políčko má cenu v sekundách pro tebe.
  • V ní najde časově nejrychlejší cestu mezi kontrolami a porovná ji s tou, kterou jsi běžel.

No AI and no paid services: just geometry, the map and your data.

How the calculation works under the hood
  • From the map without a course the program reads the terrain colours: how runnable the forest is, where the paths are and what is an obstacle (cliff, water, fenced area).
  • It adds detailed elevation data (slope from the Czech ČÚZK DMR 5G model).
  • Using your personal speed model it builds a grid in which every cell costs a number of seconds for you.
  • In that grid it finds the time-fastest path between controls and compares it with the one you ran.

Jak začít

How to start

  1. Stáhni a nainstaluj program

    Windows: Klikni na tlačítko Získat v Microsoft Store. Otevře se stránka aplikace v Microsoft Storu, kde zvolíš instalaci. Další aktualizace se budou instalovat přes Microsoft Store.

    Mac: Použij tlačítko pro stažení DMG nahoře a postupuj podle návodu níže.

    Mac napíše, že aplikaci nelze otevřít
    1. Otevři stažený soubor a přetáhni ikonu do složky Aplikace.
    2. Spusť aplikaci. Mac ji napoprvé neotevře, hlášku zavři.
    3. Otevři Nastavení systému → Soukromí a zabezpečení, sjeď dolů a klikni na Přesto otevřít. Potvrď heslem.
    4. Napříště se aplikace otevře normálně.

    Jaký máš čip, zjistíš v nabídce s jablkem vlevo nahoře → O tomto Macu. U Macu s Intelem instalátor zatím nefunguje, viz spuštění přes Docker.

    Download and install the program

    Windows: Click the Get it from Microsoft Store button. The app's Store page will open; choose Install there. Future updates will be delivered through Microsoft Store.

    Mac: Use the DMG download button above and follow the instructions below.

    Mac says the app cannot be opened
    1. Open the downloaded file and drag the icon into Applications.
    2. Start the app. The first time the Mac will refuse; close the message.
    3. Open System Settings → Privacy & Security, scroll down and click Open Anyway. Confirm with your password.
    4. From then on the app opens normally.

    You can see your chip in the Apple menu (top left) → About This Mac. The installer does not work on Intel Macs yet, see running with Docker.

  2. Mapa z Liveloxu (KMZ)

    1. Otevři svůj závod a kategorii na Livelox.
    2. Vpravo nahoře klikni na ikonu tří čárek (menu) a zvol stažení mapy ve formátu KMZ. KMZ je mapa, která „ví“, kde přesně leží; obyčejný obrázek to neumí.
    3. Stáhni ji dvakrát: jen mapu (bez tratě) a s tratí (s kontrolami). Z první program čte terén, z druhé kontroly.

    Když Livelox stažení nedovolí, zkus velký snímek obrazovky či fotku papírové mapy. Mapa patří pořadateli: používej ji jen pro sebe.

    The map from Livelox (KMZ)

    1. Open your race and class on Livelox.
    2. In the top right corner, click the three-lines menu icon and choose to download the map in KMZ format. A KMZ map “knows” exactly where it lies; a plain image does not.
    3. Download it twice: map only (no course) and with course (with controls). The program reads the terrain from the first and the controls from the second.

    If Livelox does not allow downloading, try a large screenshot or a photo of the paper map. The map belongs to the organiser: use it for yourself only.

  3. Záznam z hodinek (.zip nebo .fit)

    Z webu Garminu se vždy stáhne soubor .zip. Nerozbaluj ho, nahraj ho do programu rovnou. Soubor .fit dostaneš jen při stažení přímo z hodinek kabelem.

    • Garmin Connect na počítači (connect.garmin.com, v mobilní aplikaci to nejde): otevři závod, vpravo nahoře klikni na ozubené kolo → Exportovat originál. Stáhne se soubor .zip, ten nerozbaluj a nahraj ho do programu tak, jak je.
    • Všechno najednou: na garmin.com si můžeš vyžádat hromadný export všech dat. Přijde e-mailem jako .zip, někdy až za několik dní. Program si z něj závody vybere sám podle data a místa.
    • Přímo z hodinek kabelem: připoj hodinky k počítači, ve složce GARMIN/Activity vyber soubor .fit s datem závodu.

    The watch recording (.zip or .fit)

    The Garmin website always gives you a .zip file. Do not unpack it; upload it to the program as it is. You only get a .fit file when you copy it straight from the watch with a cable.

    • Garmin Connect on a computer (connect.garmin.com, the phone app cannot do it): open the race, click the gear icon in the top right → Export Original. You get a .zip file; do not unpack it, upload it to the program as it is.
    • Everything at once: on garmin.com you can request a bulk export of all your data. It comes by e-mail as a .zip, sometimes after several days. The program picks the races by date and place itself.
    • Straight from the watch with a cable: connect the watch to the computer and pick the .fit file with the race date from GARMIN/Activity.

  4. Spusť rozbor v programu

    Přidej závod a nahraj obě mapy a záznam běhu. Rozbor se spočítá sám, trvá to pár minut.

    Program se otevře ve vlastním okně, nic se nepřihlašuje. V Profilu můžeš zadat registrační číslo ORIS, program pak načte tvoje závody a oficiální mezičasy sám. Při výpočtu je potřeba internet kvůli výškopisu.

    Run the analysis in the program

    Add the race and upload both maps and the run. The analysis runs by itself in a few minutes.

    The program opens in its own window, no login. In the Profile you can enter your ORIS registration number, and the program then loads your races and official splits by itself. The calculation needs the internet for the elevation data.

Tvoje data zůstávají u tebe

Your data stays on your device

Program běží na tvém počítači. Mapy ani záznamy z hodinek (.fit) se nikam nenahrávají, žádný účet u nás, žádný server, žádné sledování. Z internetu si program bere jen veřejné údaje: závody a mezičasy z ORIS a výškopis (kopce).

The program runs on your computer. Maps and watch recordings (.fit) are never uploaded: no account with us, no server, no tracking. It only fetches public data from the internet: races and splits from ORIS and the elevation (hills).

Linux, Mac s Intelem a pro programátory

Linux, Intel Macs and developers

Běžný uživatel Windows nebo nového Macu tohle nepotřebuje, stačí tlačítko nahoře. Na Linuxu a Macu s Intelem spustíš program ze zdrojového kódu s Dockerem (potřebuješ Docker a git, příkazy zadáš do terminálu):

On Windows or a recent Mac you do not need this, the button above is enough. On Linux and Intel Macs, run it from the source code with Docker (you need Docker and git; type the commands into a terminal):

git clone https://github.com/Polik9000/Kudy-jsem-mel-bezet.git
cd Kudy-jsem-mel-bezet
docker compose up --build

Pak otevři http://localhost:8000/ob/. V repozitáři nejsou žádné mapy ani běhy, nahraješ si vlastní.

Then open http://localhost:8000/ob/. The repository has no maps or runs; you upload your own.

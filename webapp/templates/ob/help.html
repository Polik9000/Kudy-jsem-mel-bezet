{% trans %}Mapa z Livelox (KMZ){% endtrans %}

  1. {% trans %}V Livelox vyber závod a svou kategorii. Odkaz na Livelox bývá u závodu v appce.{% endtrans %}
  2. {% trans %}V zobrazení mapy klikni vpravo nahoře na tři čárky a vyber Stáhnout mapu (Download map).{% endtrans %}
  3. {% trans %}Stáhni dvakrát: Mapa s tratí, formát KMZ, a Pouze mapa, formát KMZ.{% endtrans %}
  4. {% trans %}V Podkladech závodu nahraj první jako mapu s tratí a druhou jako mapu bez tratě.{% endtrans %}

{% trans %}Z mapy s tratí appka čte kontroly, z mapy bez tratě terén pro nejlepší postupy. Mapu bez tratě stačí, když nahraje jeden člověk z oddílu. Mapy vidí jen přihlášení členové a z appky nejdou stáhnout.{% endtrans %}

{% trans %}Když Livelox stažení nedovolí{% endtrans %}

{% trans %}Pořadatel může stahování map vypnout. Pak máš dvě cesty:{% endtrans %}

  • {% trans %}Nejlíp fotka papírové mapy. Vyfoť celou mapu shora, za světla a bez blesku. Mapu polož rovně a nic ať nezakrývá kontroly. Nahraj ji v Podkladech jako fotku mapy. Na místo se usadí sama podle kontrol a tvé stopy (potřebuje běh z hodinek a mezičasy z ORIS); když se neusadí, jde usadit ručně.{% endtrans %}
  • {% trans %}Jinak dva snímky obrazovky z Livelox (níže). Jen pro vlastní rozbor: nesdílej je dál, pořadatel stažení vypnul záměrně.{% endtrans %}

{% trans %}Dva snímky z Livelox (Chrome na počítači){% endtrans %}

  1. {% trans %}Stiskni F12 a pak Ctrl+Shift+M (zobrazení zařízení). Nahoře u Dimensions zvol Responsive a nastav 5000 × 4000.{% endtrans %}
  2. {% trans %}V Livelox zavři křížkem postranní panel se závodníky. Mapu přibliž co nejvíc tak, aby byla celá vidět.{% endtrans %}
  3. {% trans %}Tři tečky úplně vpravo v liště s Dimensions → Capture full size screenshot. Snímek se uloží do Stažených. To je snímek s tratí.{% endtrans %}
  4. {% trans %}Mapu neposouvej ani nepřibližuj. V Livelox vpravo dole klikni na malý výstupek, vysune se panel nastavení. Druhý posuvník dej úplně doleva, tím zmizí kontroly a trať. Panel zavři křížkem vpravo nahoře, těsně pod ozubeným kolečkem.{% endtrans %}
  5. {% trans %}Znovu tři tečky → Capture full size screenshot. To je snímek bez tratě.{% endtrans %}
  6. {% trans %}Oba snímky nahraj do polí „Snímek z Livelox s tratí“ a „Snímek z Livelox bez tratě“ v Podkladech závodu.{% endtrans %}

{% trans %}Proč neposouvat: appka usadí jen snímek s tratí (podle kontrol a tvé stopy) a snímku bez tratě dá stejné místo. Snese posun o pár pixelů, ne jiné přiblížení nebo jinou velikost okna.{% endtrans %}

{% trans %}Když pořadatel nahrál mapu s kontrolami natvrdo, trať vypnout nejde. Pak zbývá fotka mapy. Snímek s tratí jde nahrát i tak, nejlepší postupy z něj ale nebudou.{% endtrans %}

{% trans %}Ztratil jsem se u kontroly{% endtrans %}

{% trans %}Rozbor po závodě pro chvíli „byl jsem u kontroly, neviděl jsem ji a nevěděl jsem přesně, kde jsem“: co tam bylo vidět a jak ses měl vrátit. Na závodě se mobil ani jiné pomůcky používat nesmějí, stránka je na doma. Otevřeš ji tlačítkem Ztratil jsem se u kontroly na stránce závodu (nebo u úseku v části Kdyby ses ztratil). Potřebuje mapu s tratí a mapu bez tratě; s během (.fit) ukáže i místa ze stopy.{% endtrans %}

  1. {% trans %}Poprvé se mapa kolem kontrol asi minutu připravuje.{% endtrans %}
  2. {% trans %}Nahoře vyber kontrolu.{% endtrans %}
  3. {% trans %}S během: Po závodě: kde jsem se ztratil ukáže místa u kontroly, kde ses podle stopy zdržel.{% endtrans %}
  4. {% trans %}Bez běhu, nebo když stopa místo nechytila: Kde jsem asi byl. Ťukni do mapy, kde jsi asi byl, a vyber, o kolik si nejsi jistý (25, 50, 100 nebo 150 m; v lese je výchozí 50 m, na sprintu 25 m). Oranžový kruh je místo, kde jsi mohl být.{% endtrans %}
  5. {% trans %}Appka napíše jednu až tři věty: kam jsi měl jít, podél čeho, kde byla kontrola. Modrá čára ukazuje cestu, čísla jsou záchytné body.{% endtrans %}
{% trans %}Nedalo se minout{% endtrans %}
{% trans %}Dlouhá věc (cesta, vodoteč, plot, okraj zástavby nebo velké paseky), na kterou bys narazil odkudkoli z kruhu, kdybys šel daným směrem. Appka vybere nejjistější, ne nejbližší.{% endtrans %}
{% trans %}Neměl jsi hádat směr ke kontrole{% endtrans %}
{% trans %}Když byla jistá věc dál, než je kruh nejistoty, appka radí, že jsi měl dojít (nebo se vrátit) nejdřív k ní a teprve odtud ke kontrole.{% endtrans %}
{% trans %}Jen kontrola a okolí{% endtrans %}
{% trans %}Když vůbec nevíš, kde jsi byl: co bylo kolem kontroly nejjistější.{% endtrans %}
{% trans %}Po závodě: kde jsem se ztratil{% endtrans %}
{% trans %}Místa do 100 m od kontroly, kde jsi podle stopy zpomalil, kroužil nebo se otočil. U každého, co jsi měl vidět a kudy se vrátit.{% endtrans %}
{% trans %}Popis kontroly{% endtrans %}
{% trans %}Nepovinný, napíšeš ho ručně (třeba „kupka, severní úpatí“). Ukáže se v radě, nic se z něj nepočítá.{% endtrans %}

{% trans %}Rada je odhad z kresby mapy, bez vrstevnic a skal. Do oplocených a zakázaných míst nevede.{% endtrans %}
